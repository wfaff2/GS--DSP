# MARSIM Depth-CBF M2.5 定量验证报告

结论：**M2.5 NOT READY**。本结论只针对将当前局部二次 Depth-CBF 继续接入 M3；不否定 M1/M2 软件链已正确贯通，也不涉及 ACADO、HOCBF 或闭环避障。

## 1. 范围和证据边界

- 工程：`code/仿真/惯性 VS 非惯性`，ROS package 为 `coni_mpc`。
- 正式算法点云输入仅为 `/quad0_pcl_render_node/sensor_cloud`；MARSIM `/cloud`、解析几何和 PCD 仅用于地图发布或离线真值评估，没有进入预处理或回归器。
- 使用 MARSIM CPU `pcl_render_node`、Livox Avia 模式、10 Hz、水平 FOV 70.4°、垂直 FOV 77.2°、地图/局部滤波体素 0.1 m。
- 固定 UGV 为世界坐标原点；UAV 使用测试专用确定性位姿发布器。没有控制器、避障反馈或动态障碍物。
- 解析场景为 A1 平面、A2 圆柱、A3 直角墙、A4 双圆柱切换；另运行 MARSIM 官方 `small_forest01cutoff.pcd`。
- 共 19 个运行、1345 帧；其中 1203 帧属于排除盲区/FOV 专项后的名义集合。所有帧均保留；不可用量写为 NaN，并同时记录 `valid` 和 `failure_reason`。

## 2. 指标定义

- `d_lidar`：经正式 L→B→W 变换及配置范围过滤后，UAV 中心到最近 LiDAR 回波的距离。
- `d_GT`：解析表面的精确距离；官方地图使用原始高分辨率 PCD KD-tree 最近距离。它只在评估器内计算。
- `h_raw(p)=min_j ||p-q_j||²-d_safe²`；`h_fit` 是 M2 的同一局部二次回归结果。
- 安全边界沿 UAV 中心指向当前最近 LiDAR 点的射线做采样括区和 50 次二分。`signed_boundary_shift=s_fit-s_raw`；负值表示拟合边界更早触发（保守），正值表示更晚触发（非保守）。
- 原始梯度方向为归一化 `2(p-q*)`；拟合梯度来自 `2A(p-center)+b`。跳变由相邻有效帧单位方向夹角计算，没有低通滤波。
- 计时使用 `steady_clock`，分别记录预处理、KD-tree、查询点生成、最近邻查询、回归和总算法链；GT、根搜索及 CSV I/O 不计入总算法时间。

用户没有给定论文级验收阈值，因此报告采用明确的工程就绪门槛：名义有效率≥95%，LiDAR 距离 P95≤0.15 m，中心拟合误差 P95≤0.05 m²，边界误差 P95≤0.10 m，梯度角 P95≤15°，算法链 P95≤20 ms，且同步拒绝为 0。实际值和门槛均保存在 `acceptance_criteria.csv`，便于以后替换门槛而不重跑数据。

## 3. Q1–Q7 结论

### Q1. LiDAR 表面距离与真值是否一致

只在无遮挡且最近表面位于 FOV 内时一致。A1 平面中位绝对误差为 `3.81e-6 m`，A4 双圆柱总体 MAE 为 `0.0163 m`；但 A2 P95 为 `0.324 m`，A3 为 `0.800 m`，官方地图为 `2.113 m`。名义帧合并 P95 为 `0.391 m`，未通过 0.15 m 门槛。

A3 frontal 轨迹是一个可解释的反例：全局最近的是侧向墙，但它在 Avia 水平 FOV 外，传感器返回前向墙。因此 `d_lidar` 与“全局最近表面真值”不等价。官方地图也存在相同的可见性/遮挡差异。该结果说明后续不能把当前单向 LiDAR 回波距离未经可见性定义直接解释为全局净空。

### Q2. 局部二次拟合是否逼近原始离散障碍函数

A1 中心误差 P95 为 `0.00264 m²`，表现良好；A2、A3、A4、官方地图分别为 `0.1041`、`0.2355`、`0.0549`、`0.0874 m²`。合并名义 P95 为 `0.2204 m²`，未通过 0.05 m² 门槛。回归器自身的残差阈值仍全部满足，说明“对 125 个查询样本的最小二乘残差有效”不等价于“UAV 中心或安全边界处足够准确”。

### Q3. 拟合零水平集是否贴合原始安全边界

A1 的边界绝对误差 P95 为 `0.00542 m`；A4 为 `0.0757 m`。A2、A3、官方地图分别达到 `0.178`、`0.856`、`0.186 m`。名义合并 P95 为 `0.762 m`，未通过 0.10 m 门槛。

边界偏移不是单向保守。采用 YAML 中 `0.001 m` 容差后，A1 的非保守比例为 `98.8%`；A3 为 `41.5%`，且同时存在较大的负偏移。因此当前拟合不能被描述为天然保守，需要 M3 前建立显式的边界误差预算或保守化策略。

### Q4. 拟合梯度方向是否合理

A1 梯度角 P95 为 `2.40°`，A4 为 `20.67°`；A2、A3、官方地图分别为 `35.53°`、`37.53°`、`32.83°`。名义合并 P95 为 `37.25°`，未通过 15° 门槛。偏差集中在曲面、角点、可见表面变化和最近点切换附近。

### Q5. 切换区域是否更平滑

是，但平滑不等于准确。在专用 switching 轨迹上，A3 的原始梯度跳变 P95 为 `74.92°`，拟合后降为 `1.53°`；A4 从 `6.22°` 降为 `4.73°`。二次拟合显著抑制最近点离散切换，但 Q4 表明它可能以方向偏置换取平滑，不能仅依据跳变变小判定可用于控制。A4 三次 GT 障碍 ID 切换的时间戳与位姿已单独写入 `switch_events.csv`。

### Q6. 实时性与有效率

名义帧有效率为 `99.42%`，同步拒绝为 0；三路消息由同一测试时钟发布，实测 mean/P95/max 偏移均为 0 ms。各场景算法链 P95 为 `1.24–8.46 ms`，合并名义 P95 为 `7.93 ms`；1203 个名义帧中 5 帧超过 10 ms、0 帧超过 20 ms。当前 CPU MARSIM 10 Hz 条件下实时性通过。

失效全部为 `EMPTY_CLOUD`：A1 盲区专项 28 帧，A2 的 FOV 专项和 frontal 轨迹共 42 帧。没有出现 `INSUFFICIENT_SUPPORT`、秩亏、条件数、RMSE、最大误差或同步拒绝。该统计不能被解读为场景始终安全，因为空云正是传感器不可观测。

### Q7. 最小射程盲区如何影响链路

在 A1 大平面逼近实验中保持当前 `min_raylength=1.0 m`，真值距离 `<0.5 m` 时回波/有效率均为 `0%`；`0.5–1.0 m` 为 `43.75%`；`1.0–1.5 m` 为 `100%`。传感器在 `d_safe=0.15 m` 边界之前已经失去观测，因此这是阻止进入 M3 的独立安全问题。FOV 扫描中，真实 bearing `70–90°` 的回波/有效率仅 `5.4%`，而 `≤70°` 的各分箱为 100%。这说明失效模式必须区分“完全空云”和“最近真实表面不可见但仍有较远回波”。

## 4. 就绪判定

通过项：19 个运行齐全、名义有效率、同步、20 ms 实时性。

未通过项：LiDAR–全局 GT 距离、中心拟合、零水平安全边界和梯度方向四项 P95。当前最危险的证据是局部拟合可在残差阈值内保持 `valid=true`，但安全边界仍可能产生大幅且非单向偏移。

因此在进入 M3 前至少需要决定并验证：GT 是否应定义为“传感器可见表面”而非全局最近表面；盲区内如何失效安全；曲面/角点是否分段拟合或采用保守包络；以及如何把实测边界误差纳入 `d_safe`。这些属于下一阶段设计决策，本次没有擅自修改算法。
