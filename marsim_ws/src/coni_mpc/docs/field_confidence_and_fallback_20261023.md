# 三维置信度 Field 与按时间回退：2026-10-23 当前实现

活动入口为 `roslaunch coni_mpc dsp_mpc_sim.launch`，默认读取
`parameters/num_sim_non_one_point.yaml`。本次取消水平投影及高度差硬筛选，
并修复旧计划以 5 倍速度消耗的问题。ACADO 仍使用已有的仿射 Field 行接口，
没有改动维度、动力学或生成求解器。

## 旧计划的时间轴

控制更新为 20 ms，预测输入每段持续 100 ms，20 段覆盖 2 s。
成功求解时缓存整个输入矩阵及本轮公共逻辑时间 `t0`。失败时选择
`j=floor((t-t0)/0.1)`，并截到 `[0,19]`。

| 距上次成功的时间 | 失败时执行的旧输入 |
| --- | --- |
| 20、40、60、80 ms | `u0` |
| 100、120、140、160、180 ms | `u1` |
| 200 ms | `u2` |
| 360 ms | `u3` |

因此“下一周期用下一段”只有在控制周期与预测段长相同时才成立。
本项目不能每次失败就把下标加一。同周期重复调用不推进；跳过周期按经过时间推进；
新成功计划重新计时；时钟退到缓存计划起点之前则使该缓存失效。
同周期求解后的 refinement 被拒绝时，恢复原成功计划及原起点。
达到最后一段后沿用原有末段保持行为并标记，尚未构造终端安全控制器。

## 当前空间场

对三维网格中心 `c_i`，令

```
q_i = p-c_i
s_i = sqrt(q_i.dot(q_i)+epsilon^2)
rho_i = s_i-epsilon
B = uav_radius + sqrt(3)/2*voxel_size + distance_margin
z_i = rho_i-B
Q(x) = x^3*(10-15*x+6*x^2), x clipped to [0,1]
g_i = Q(P_i/P_core)
```

不修改 `q.z()`，所有高度层保留各自真实三维距离。不同高度单元是不同空间支撑，
不应合并为同一个障碍点；修复的是把它们强制变成相同 XY 距离后重复施加完整贡献。
邻近真实体素仍共同构成障碍物，LSE 的密集支撑效应仍存在。

空间核 `c(rho)` 在 `rho<=R-width` 为 1，在 `rho>=R` 为 0，
过渡段为 `Q((R-rho)/width)`。当前 `R=2 m`、`width=0.5 m`。
这是球形作用域及其光滑过渡，没有额外的 `±0.6 m` 高度带。

```
S = exp(-H_clear/sigma)
    + sum_i g_i*(1+alpha*P_i)*c(rho_i)*exp(-z_i/sigma)
h = -sigma*log(S)
```

当前 `P_core=0.15`、`H_clear=1 m`、`sigma=0.05 m`、`alpha=0`。
`0.15` 是显式工程置信度选择，不是已标定的碰撞概率阈值。
P 趋近 0 时贡献及其前两阶占据率导数平滑趋于 0；P 达到 core 后权重为 1。
空支持集合的 `h=H_clear`，梯度、Hessian、`hdot` 和 `lf2` 均为 0，约束不激活。
`d_min` 仍是选中正概率体素的未加权几何诊断量；`d_softmin=h+margin` 现在含置信度，
不得把它当作全部正概率体素的距离下界。

## 导数及连续性

令 `n=q/s`、`J=I/s-qq^T/s^3`，单项 `F=w*c*exp(-z/sigma)` 的空间导数为

```
grad(F) = w*exp(-z/sigma)*(c'-c/sigma)*n
Hess(F) = w*exp(-z/sigma)*[
    (c''-2*c'/sigma+c/sigma^2)*n*n^T + (c'-c/sigma)*J]
grad(h) = -sigma*grad(S)/S
Hess(h) = -sigma*(Hess(S)/S-grad(S)*grad(S)^T/S^2)
```

代码用共同指数缩放避免上溢；`c'`、`c''` 均进入解析导数。
以每点相对速度 `v-v_i` 和不含控制的相对加速度
`a_ni-lambda*v-a_i` 计算 `Sdot`、`Sddot`，再取
`hdot=-sigma*Sdot/S`、`lf2=-sigma*(Sddot/S-(Sdot/S)^2)`。
继续输出 `A=lambda*grad(h)`、
`b=-(lf2+(gamma1+gamma2)*hdot+gamma1*gamma2*h)` 的原有仿射接口。

固定地图快照及预测切片内，场对空间为 C2，包括内外过渡边界。
预筛选使用与核完全一致的 `rho<R`，边界移除项及其前两阶空间导数均为 0。
地图替换、预测切片切换和 MPC 活跃集切换不因此获得时间连续性或连续控制指令保证。

## 保守性适用范围

配置校验要求 `R-width>=B`。若某个 `P_i>=P_core` 的体素满足 `z_i<0`，
则其处于核的常值区、`g_i=1`、`1+alpha*P_i>=1`，所以
`S>=exp(-z_i/sigma)`，从而 `h<=z_i<0`。
因此 `h>=0` 排除穿入任何高置信体素的 UAV 外接球、体素外接球及余量包络。
真实障碍物由这些体素覆盖仍是额外感知假设；低置信支撑降权后，不再对每个
`P>0` 体素提供上述完整包络保证。该性质也不等于离散闭环安全、递归可行性，
或已执行回退控制在当前真实状态下满足全部约束。

## 高度带与雷达视场

旧 `±0.6 m` 是围绕预测位置的人工高度差门限，用于限制平面投影纳入哪些高度层；
它不是三维距离，也不是雷达型号决定的必要数值。本次删除。
随后已按 Livox MID-360 官方规格将活动 launch 的垂直视场由 90 度改为
59 度（传感器坐标系仰角 -7 到 +52 度），并使渲染网格中心为 +22.5 度。
角度视场对应的可见高度随距离变化，
不能等价成固定高度差；DSP 也可能保留历史观测及预测。
因此删除高度门限是恢复三维几何的选择，不能由有限视场推断未观测空间为空。
