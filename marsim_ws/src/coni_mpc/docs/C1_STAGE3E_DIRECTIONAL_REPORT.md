## 2. 固定候选及核

令 `a=2Delta>0, y=q-c_j, r=||y||`。`y!=0` 时 `u=y/r`，定义

```text
alpha = sqrt(3) / [2(1+1/sqrt(3))²]
      = 3sqrt(3)-9/2 = .3480762113533159
S(u) = sum_k (u_k²-1/3)²
b(u) = a[sqrt(3)-alpha S(u)]
d_E(y) = max(0, r-b(u)); d_E(0)=0.
```

没有更换常数、平滑距离或修改核。记物理半径 `r_c>0`、过渡宽度 `w>0`，

```text
phi(d)=1                         d<=r_c
phi(d)=g((r_c+w-d)/w)             r_c<d<r_c+w
phi(d)=0                         d>=r_c+w
g(z)=6z^5-15z^4+10z^3.
R_E(q,t)=sum_j M_j(t) phi(d_E(q-c_j)).
```

`M_j` 保持原始非负 PHD 质量，不解释为概率，也不把 `R_E` 限制在 `[0,1]`。

## 3. 解析门控：支持函数和距离

**定理 1：对任意三维单位方向，`a||u||_1 <= b(u) <= a sqrt(3)`。**

设 `t_k=|u_k|, s=1/sqrt(3), A=sum_k(t_k-s)²`。由 `sum t_k²=1`，

```text
sqrt(3)-sum t_k = (sqrt(3)/2) A
S = sum_k (t_k-s)²(t_k+s)² <= (1+s)² A
alpha S <= sqrt(3)-||u||_1.
```

乘以 `a` 即证明下界；`S>=0` 证明上界。
该推导对零分量、坐标轴、坐标平面及各符号方向均成立；
证明中使用绝对值不意味着实际候选含绝对值的微分奇点。
又 `S=sum u_k^4-1/3`，所以 `0<=S<=2/3`，得到更精确的

```text
3a/2 <= b(u) <= sqrt(3)a.
```

坐标轴上 `b=1.5a`，对角线上 `b=sqrt(3)a`。
相比 3A，最多减少半径 `a(sqrt(3)-1.5)`，约为球半径的 13.397%；
对角方向完全没有半径改进。

**定理 2：`d_A <= d_E <= d_C`，其中 `d_C` 是精确欧氏立方体距离。**

对 `C=[-a,a]^3` 中的任意 `z`，支持函数为 `h_C(u)=a||u||_1`，且

```text
||y-z|| >= u·(y-z) >= r-h_C(u) >= r-b(u).
```

取 `inf_z` 并与零取最大值得 `d_C>=d_E`。
因为 `b<=sqrt(3)a`，又有
`max(0,r-sqrt(3)a)<=max(0,r-b)`，即 `d_A<=d_E`。
原点处三者均为零。
这里使用支持平面得到距离下界，**没有把径向差值说成精确欧氏投影距离**。

## 4. 解析门控：风险夹逼和失效条件

若所有正粒子权重 `w_i>=0`，所有 cubic 系数 `N_ij>=0`，
`sum_j N_ij=1`，且每个非零支持粒子都满足 `p_i-c_j in C`，则

```text
||q-p_i|| >= d_C(q-c_j) >= d_E(q-c_j) >= d_A(q-c_j).
```

对非增核 `phi` 逐项反序，乘 `w_i N_ij` 并完整求和；
利用 `M_j=sum_i w_i N_ij` 得

```text
R_hard <= R_smooth <= R_C <= R_E <= R_A.
```

`R_hard<=R_smooth` 使用平台包含硬碰撞指示函数。
3D 原证明另有 `R_C<=R_D<=R_A`；本节不推出 E、D 的次序。

非负质量本身不够：还需要它们确实是完整粒子投影。
删掉边界质量、只取近邻节点、Top-N 或经验窗口，均不能保留上述分割统一求和。
候选定义不补偿这些信息损失。

## 5. 解析门控：空间 C² 和解析导数

定义光滑分支 `f(y)=r-a sqrt(3)+a alpha S(y/r)`，`y!=0`。
**距离 `d_E` 本身不是全局 C²；最终核 `psi(y)=phi(d_E(y))` 是全局 C²。**

- 原点：`b>=1.5a`，故 `r<1.5a+r_c` 的整个球邻域中 `psi=1`。
  不需要在原点计算方向、范数导数或 Hessian。
- `f=0` 的正部切换：其邻域仍在 `d_E<r_c` 平台中，风险的各空间导数为零。
- 坐标轴、平面对称方向和对角线：`S=sum y_k^4/r^4-1/3` 在非零点为光滑有理函数，
  没有 cube active-set 切换或绝对值导数。
- `f=r_c`、`f=r_c+w`：`phi'`、`phi''` 在两端均为零，
  而 `grad f,H_f` 在这些非零接缝处有限，因此一阶、二阶导数连续拼接。
- 每次投影的节点数有限，有限和保留 C²；无穷网格需局部有限性或另行证明收敛。

这证明的是最终复合风险，不是从数值差分反推光滑性。
本实现保留现有 C++ 的正物理半径、正宽度条件，不声称这是候选光滑性的最弱条件。

令 `T=sum y_k^4, r=||y||`。在核过渡区，

```text
S = T/r^4 - 1/3
grad S = 4y^3/r^4 - 4Ty/r^6
H_S = 12diag(y²)/r^4 - 16(y^3 y^T + y (y^3)^T)/r^6
      - 4T I/r^6 + 24T yy^T/r^8
grad f = u + a alpha grad S
H_f = (I-uu^T)/r + a alpha H_S
grad psi = phi'(f) grad f
H_psi = phi''(f) grad f grad f^T + phi'(f) H_f.
```

平台和支撑外部直接返回零梯度、零 Hessian。
`S` 是零次齐次函数，所以 `u·grad S=0`，
`||grad f||²=1+(a alpha)²||grad S||²`，一般大于 1。
因此不能套用“欧氏距离梯度单位范数”或 1-Lipschitz 的推论。

## 6. 时间和混合导数是独立条件

固定中心、固定 `Delta,r_c,w`，如果 `M_j(t)` 各自 C²，则

```text
R_t = sum M'_j psi_j
R_tt = sum M''_j psi_j
grad R_t = sum M'_j grad psi_j
grad R = sum M_j grad psi_j
H_R = sum M_j H_psi_j
dR/dt = R_t + grad R·v
d²R/dt² = R_tt + 2 grad R_t·v + v^T H_R v + grad R·a.
```

这是当前一般二阶风险 barrier `h=tau-R` 构造所需的导数组合；
若 `tau` 随时间改变，还需要它的相应导数。
固定粒子权重、CV 轨迹与 cubic B-spline 在完整网格上确实产生 C² 质量轨迹；
跨单元支持启闭时，延拓到零的 `M,M',M''` 连续。
独立测试在一个粒子恰好跨 `p_x/Delta=1` 时核验这些导数。

空间 C² **不会**保证新感知快照、粒子出生/死亡、重采样、改权、阈值筛选、
预测切片切换或网格重定位的时间 C²。当前在线接口不提供一条已证明 C² 的完整质量时间曲线。
这属于接口缺口，不能用本次 CV 模型测试填补。

若节点只平移而方向坐标轴固定，还需

```text
R_t = sum [M' psi - M grad psi·c']
R_tt = sum [M'' psi - 2M' grad psi·c'
             + M(c'^T H_psi c' - grad psi·c'')]
grad R_t = sum [M' grad psi - M H_psi c'].
```

非惯性 frame 的旋转也会改变方向 envelope 的轴，不能只移动节点中心。
对 affine frame 关系 `x=J(t)z+s(t)`，在固定 `z` 的 `x_t,x_tt` 下，

```text
Rhat_t = R_t + grad R·x_t
Rhat_tt = R_tt + 2 grad R_t·x_t + x_t^T H_R x_t + grad R·x_tt
grad_z Rhat_t = J^T(grad R_t + H_R x_t) + J_t^T grad R.
```

本次实验仅验证固定网格，没有实现旋转场接口或跨快照时空导数。

## 7. E 与 D：不能预设改进次序

**解析反例否定“E 总比 D 紧”。** 沿坐标轴 `y=(r,0,0), r>1.5a`：

```text
d_E = r-1.5a
d_D = r-3^(1/4)a
d_E < d_D.
```

取 `a=1,r=2.2,r_c=.48,w=.5`，二者位于核过渡区，故 `phi(d_E)>phi(d_D)`。
这不是候选的保守性失败，只说明 E 不能充当 D 的统一紧致改进。
本审计没有证明反方向的全局 `R_D<=R_E`；有限样本发现这个次序不能升级为定理。

## 10. 导数数值核验与裁剪反例

33 个过渡点覆盖坐标轴、平面对角、三维对角和随机方向，
梯度使用值的中心差分，Hessian 使用梯度的中心差分，步长 `2e-5`：

```text
max gradient error = 3.6750e-9

```

正部切换及核两个接缝均检查左右；`eps=1e-6` 时最大 Hessian 差约 `1.2114e-4`，

常值邻域和轴/符号/坐标置换性质也通过。

```text
R_t central-FD error       = 8.2635e-12
R_tt (FD of R_t) error     = 1.6589e-8
grad R_t central-FD error  = 3.3578e-11
sum(M,M',M'')              = (1.7, -4.52e-17, 2.25e-16).
```

边界反例：`p=(.2,.3,.4), Delta=1, dimensions=8`，故意裁剪后保留质量
`.8313326062`、丢失 `.1686673938`；粒子位置的真实 smooth 风险为 1，E 只得到
`.8313326062`，违反上界。正常有限支持参考路径对此抛异常。

局部查询裁剪反例：`p=(3.37,3.23,3.19), Delta=1`，64 个节点只保留最近一个，
E 风险为 `.2181419723`，低于 smooth 风险 1。
所以不能靠近邻/Top-N 获得本实验的成本优势。

允许的**精确零剪枝**有独立证明：若
`||q-c_j|| >= sqrt(3)a+r_c+w`，则球距离已不小于核外边界，
由已证明距离次序，A/C/D/E 的值、一阶、二阶空间核项都为零。
固定网格的时间/混合项同样为零。测试与完整求和比较一致。
E 自身 `d_E>=r_c+w` 也是精确零条件。
这只适用于当前查询及当前导数，不能把该节点从未来移动查询的永久数据结构中删掉。
**正式计时没有使用上述剪枝，所有节点均参与距离求值。**

## 11. 分项成本

同一数组、同一三查询（场景第一查询、`(2.5,1,.2)`、原点）、
`Delta=.5,r_c=.48,w=.5`；一次预热，五次计时取中位数。
`value/gradient/hessian` 分别仅形成相应输出；`full` 同时形成三者。
D 的导数路径保留同一次 KKT 的投影/乘子，没有重复求解投影。
所有模式访问全部节点；P2G 在查询前单独计时，不混入每查询成本。

P2G 中位数：单粒子 `.027904 ms`，稀疏六粒子 `.164559 ms`，密集四十粒子 `1.191557 ms`。

密集场景 551 节点的每查询中位数（ms）：

| 方法 | 值 | 梯度 | Hessian | 三者一起 |
|---|---:|---:|---:|---:|
| A | .026621 | .036938 | .052942 | .068091 |
| C | .033914 | .048773 | .069356 | .084516 |
| D | 3.209233 | 3.282438 | 3.304411 | 3.329602 |
| E | .051377 | .082343 | .138607 | .153740 |

本次密集参考实现 E 相对 D 的值/梯度/Hessian/full 成本约低 62.5/39.9/23.8/21.7 倍；
E 的 full 成本仍是 A 的约 2.26 倍。
参考成本支持“闭式方向构造具有可行的计算优势”这一研究判断。
它不证明 C++ 实时上界、完整 MPC horizon 成本或端到端加速。
NumPy 向量化、KKT 固定 64 次二分、少量重复、Python 开销和查询平台比例影响数字；
优化的 C++/缓存/KKT 容差策略可能改变倍率。
单粒子和稀疏场景的全部分项数字在 JSON 中，未与旧阶段不同计时方法的数字直接作速度比。

**决策：**

1. 数学上接受 E 为独立、可解析求导、条件明确的保守上界，不接受“E 比 D 更紧”。
2. 在未标定质量阈值上，E 相对 A 有约 6–10% 的抽样排除减少，
   但在匹配风险平均值上改善仅约 .12–4.86%，并弱于 D。
   不能宣布真实控制阈值的有意义收益已成立。
3. E 的计算优势有离线证据，适合作为便宜的研究比较器；
   本结果不足以授权在线接口修改。当前 PHD/occupancy 语义、阈值标定、
   快照时间曲线、非惯性旋转及完整质量策略仍未解决。
   停止继续围绕这个固定方向公式追求在线替换，不扩展本次实现。
4. Stage A（grid-only）仍值得保留作可证明、低成本基线，尤其供分辨率/守恒研究使用。
   但它丢弃粒子在节点支持内部的位置；任何只用总质量的无条件几何 envelope
   都必须容许很宽的支持，空间 C² 并不消除宽平台和保守排除。
5. 如开启下一项研究，优先审查 option B：节点局部位置/离散程度统计或可证明更窄的支持信息，
   连同质量守恒与时间导数语义一起设计，再证明风险上界。
   一、二阶矩不是自动安全证书，不能恢复 3B 的负 Taylor 修正，
   也不能预先保证额外统计一定有收益。

新增文件只有本报告、参考脚本、测试、JSON、SVG；`TASK_LOG.md` 仅追加本次研究摘要。
